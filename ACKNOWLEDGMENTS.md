# Protocol references and acknowledgments

Better Neewer is an independent native client. Its protocol implementation was informed by existing open-source research and comparison with the vendor application's behavior and model capabilities.

- [NeewerLite](https://github.com/keefo/NeewerLite) (MIT), especially its model mapping, effect reference and local macOS Bluetooth-address resolution approach.
- [Beacon](https://github.com/TheASDM/Beacon) (MIT), a related SwiftUI lighting controller.
- [neewer-python](https://github.com/verygeeky/neewer-python) (MIT), for independent framing/query corroboration.
- [neewer-hardware](https://github.com/verygeeky/neewer-hardware), for published protocol research. Consulted as reference; its documentation is not redistributed here.

Protocol facts were independently implemented and tested. No NEEWER application binary, asset catalogue, SDK, extracted code or private device records are distributed. The included control-panel image shows the author's original working application and was previously published on his development log.

NEEWER is a trademark of its owner. This project is not affiliated with or endorsed by NEEWER. Hardware and firmware can differ; a model label alone does not establish compatibility.
